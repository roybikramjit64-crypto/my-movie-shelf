# 🎬 My Movie Shelf

A clean, responsive React application built with **Vite** that lets users manage a personal list of favorite movies.

## Features

- **Interactive Movie List**: Browse movies complete with posters, release years, and ratings.
- **Remove & Clear**: Delete individual movie items or clear the entire list with a single click.
- **Refresh Capability**: Reset the shelf back to its original state when empty.
- **Direct Links**: Quick navigation to watch or view detailed movie info externally.
- **Responsive Dark UI**: Styled using CSS for desktop and mobile devices.

## 🛠 Tech Stack

- **Frontend Library**: React 19
- **Build Tool**: Vite
- **Styling**: Modern CSS3 (Flexbox)
